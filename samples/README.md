# 脱敏测试样本

真实样本尚未生成。用户发起测试后，将容器内加密档案经 sample_export.py 脱敏，导出到 captured/。

原始请求头、正文、响应及令牌只留在账号持久盘的加密档案；密钥不导出。派生样本保留请求头名称、多值和协议结构，自由文本、账号信息、工具参数及未知字段值均替换为同一导出批次内稳定的占位符。任意二进制和无法解码的压缩正文仅记录脱敏占位，明确不具备原始正文重放能力。

脱敏会改变字节、长度、签名和内容，因此派生样本用于结构回归，不能宣称与原始请求逐字节相同。精确重放只允许原始加密档案在无网络的回环环境中使用。

浏览器请求、网络探测不在 Go 账号 HTTP 采样范围。captured/ 默认不自动加入 Git，须经过导出检查后再单独提交。

本版新增 header_comparison：执行器最终策略覆盖前、覆盖后、实际发出的三个阶段。覆盖前指 Go 最终发送层的输入，不是用户客户端或 NewAPI 原始入口。policy_changes 与 transport_changes 分开记录；历史记录未保存前值时 available=false，不从当前配置补造。
