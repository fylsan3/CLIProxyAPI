# 真实账号测试准备与范围（2026-11-26）

本轮候选为 container-native7-audit1，底层 CPA 8.1.1。生产是否已更新以 evidence/production-upgrade-result.json 和线上只读核验记录为准，不能用构建通过代替发布成功。

## 已核对

官方 GitHub release 与 npm latest 本轮均核对为 Claude Code 2.1.332。沿用同版本未改包的 Linux ARM64 闭网 OAuth 样本；该样本不代表官方订阅接口接受情况。用户手动模型头仍声明 2.1.331，相关 Node/JS/SDK 字符串只是现有手动声明；实际执行程序是 Go。本轮没有复制官方身份、设备或账号标识，也没有修改用户手动请求头值、system 或 messages。

已通过：冷却回执及私有字段隔离、A 429/403 时 B 流式完成、双层清除确认、容器不可用不误报清除、SOCKS 半关闭与不直连、OS/架构基线、7 条 OAuth 请求和模型最终请求头、HTTP 加密归档与离线重放、脱敏金丝雀检查、A/B 全账号请求测试窗口、自动导出及不重复覆盖、旧发布版本到候选的虚构 A/B 迁移/回滚/浏览器重新打开。

Mac ARM64 中央及 Linux ARM64 执行器实测；Linux ARM64 中央已构建。本轮没有在独立 Linux 服务器上验证自启部署，也没有运行一小时真实模型任务。

## 采样与提示

- 每个已登记测试账号单独开启最多 24 小时窗口，默认关闭；到期后不为新的普通账号请求创建测试档案。
- 捕获范围：Go 最终 HTTP 发送层的换令牌、刷新、profile、roles、usage、messages、count_tokens，以及实际经过该层的重试。记录实际发出的头字段多值、方法、路径查询、正文、响应头、响应体与完整性。失败、取消、截断不能标为完整。
- 浏览器登录/验证码/网页后台请求、网络出口检查、客户→NewAPI→CPA 的入站报文不在此采样边界。本轮不抓 TLS 握手或 TCP 包，也不改浏览器。
- 完整原件与密钥留在账号卷 /state/http-samples 与 /state/http-capture.key，原件加密；不会进入 Git。
- 只有保守脱敏的派生结构样本自动进入 samples/captured/；原始用户正文、工具参数、账号和动态标识均替换。不能把脱敏结构样本当逐字节原样重放；精确离线重放使用隔离环境中的加密原件。
- 磁盘剩余低于 512 MiB 时停止新的档案或中止采样并报告不完整，不因采样破坏原业务返回。已归档数据不自动删除。
- 最终发送事件即时检查覆盖值和新增未分类头。管理页约 5 秒刷新显示；本地收集器也尝试发送系统通知。通知权限由 macOS 决定，管理页告警是主要可见渠道。
- Authorization、X-Client-Request-Id、X-Claude-Code-Session-Id、重试/超时头和 HTTP framing 是正常的凭据、CPA 动态或传输字段，不强行改成固定模型头。未知字段提示待确认，不自动删除。
- OAuth profile/roles/token 保留当前手改源码规则；usage 使用专用覆盖；模型/count_tokens 使用 12 项覆盖。不能将不同接口都称为“统一 12 项”。

## 用户发起的真实测试顺序

1. 普通非流式：经已有客户端→NewAPI→CPA 发送“请只回复 OK”。先核对实际容器、真实响应、最终头、档案完整性和脱敏文件。
2. 流式：发送短问题，核对完整结束、用量与客户端收到的内容。不要先用长任务。
3. 工具调用：在不含秘密的测试目录做一次简单文件读取，确认工具往返和下一轮历史；查看请求体与系统提示词中实际包含哪些环境字段。
4. 管理页只点一次“刷新用量”：验证 profile/usage、订阅档位、额度及重置卡只读字段。该操作不使用重置卡。
5. 按原生自动机制等待凭据轮换，观察刷新和刷新后模型调用；不要求退出账号或重新授权，也不主动重复刷新。
6. 基础用例通过后再单独验收取消、重启后恢复与一小时长任务。真实 403/429 被动记录，禁止为测试刻意打到限额。

重置卡消费未接通，不列入可用能力；浏览器流程和一小时任务验收持续保留待办。真实账号测试由用户发送，准备阶段不主动调用模型、不消费重置卡、不修改 NewAPI。
